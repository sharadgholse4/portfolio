## 🔬 Technical Skills & Interactive Systems Lab

The portfolio includes a built-in interactive engineering lab with three distinct simulation environments:

### 1. 🪐 3D Neural Skill Cosmos
- **Fibonacci Sphere Lattice**: 3D Golden Angle distribution organizing 16 engineering skills across an interactive 3D constellation.
- **Official Brand SVG Badges**: Custom SVG vector emblems (C++, Java, React, JavaScript, HTML5, PostgreSQL, MySQL, SQLite, Git, VS Code, WebSockets, Sockets, DSA, OOP, Debugging, Architecture) centered within glowing glass node discs.
- **Luminous Neural Topology**: High-visibility connecting links with real-time animated data packets illustrating semantic skill architecture.
- **Bi-Directional Telemetry Sync**: Interactive hovering and clicking on any node dynamically highlights connected links and updates the live skill inspector.

### 2. ⚡ Real-Time Network Sockets Lab
- **I/O Multiplexing Simulator**: Simulates high-throughput client-server packet flows across simulated frontend, mobile, worker, and database clients.
- **Packet Streaming & Spike Load**: Interactive controls for single transmissions, full network broadcasts, and simulated traffic spikes with real-time RTT telemetry.

### 3. 📊 Algorithm & Memory Visualizer
- **Dual-Pivot Quicksort**: Step-by-step $O(N \log N)$ partitioning, pivot tracking, and in-place bar swapping with pitch-synthesized audio feedback.
- **Dynamic Dijkstra Pathfinder**: Randomized grid pathfinding with wavefront exploration and shortest-path highlight.
- **Multi-Level B-Tree & Memory Hierarchy**: Dynamically generated 3-level B-Tree visualizer demonstrating hardware memory latencies:
  - **Level 0**: L1 Root Cache (`<0.8ns`)
  - **Level 1**: L2 Child Page Routers (`~2.5–3.5ns`)
  - **Level 2**: Leaf Node Data Pages (`~14–26ns`)
  - Real-time key search path resolution on every randomized iteration.

## ⚡ Performance & Architectural Highlights

- **0% Background CPU**: `IntersectionObserver` automatically halts Three.js and 2D Canvas animation loops when scrolled out of view.
- **GPU-Accelerated Compositing**: Hardware-accelerated transforms (`translate3d(0,0,0)`) eliminating paint bottlenecks for a silky smooth 120+ FPS experience.
- **Pure Self-Contained Architecture**: Zero heavy frontend runtime bloat; built with lightweight modern web APIs and pinned CDNs.
- **Synthesized Haptics**: Web Audio API generates lightweight procedural sine/triangle audio tones for physical tactile feedback without external audio files.

## 🚀 Local Development

Clone the repository and run any local HTTP server:

```bash
# Clone the repository
git clone https://github.com/sharadgholse4/portfolio.git
cd portfolio

# Run with Python
python -m http.server 3000

# Or run with Node.js
npx serve .
```

Open your browser at `http://localhost:3000/`.
