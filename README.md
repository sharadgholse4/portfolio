# Sharad Gholse — Systems & Software Engineer Portfolio

> A high-performance, interactive portfolio showcasing low-latency systems engineering, 3D WebGL computer graphics, concurrent network architectures, and real-time physics simulations.

---

## 🌟 Key Engineering Highlights & Interactive Labs

### 1. 🪐 3D Neural Skill Cosmos
- **Lattice Mathematics**: 3D Golden Angle (Fibonacci sphere) spatial distribution of skill nodes.
- **Perspective Projection Matrix**: Real-time 3D rotation, depth sorting ($Z$-buffer), and gyroscopic orbital guide rings.
- **Hardware Brand Logos**: Official SVG brand icons (C++, Java, React, JavaScript, SQLite, PostgreSQL, Git) rendered inside clipped glass nodes with fiber-optic energy pulses.

### 2. ⚡ Real-Time Network Sockets & Concurrency Lab
- **I/O Multiplexing Simulator**: Simulates high-throughput non-blocking Linux `epoll_wait()` / `kqueue` server architectures.
- **Bi-Directional Packet Streams**: Live TCP data packets, streaming payloads, heartbeats, and broadcast frames.
- **Throughput Oscilloscope**: Sliding buffer graph visualizing real-time throughput metrics.

### 3. 🔬 Algorithm & Architecture Visualizer
- **Dual-Pivot Quicksort**: Step-by-step $O(N \log N)$ partition, pivot selection, and in-place bar swapping with pitch-synthesized audio feedback.
- **Dynamic Dijkstra Pathfinder**: Randomized source and destination pathfinding across an 8×4 matrix with wave-front node exploration and shortest-path rendering.
- **B-Tree & Memory Hierarchy**: Visualizes hardware access latencies comparing **L1 Root Cache (<1ns)** against **L2 Child Pages (~3-4ns)**.

### 4. ⚛️ 60–144 FPS Kinetic Physics Particle Sandbox
- **Semi-Implicit Euler Integrator**: Real-time rigid body simulation with customizable gravity, air drag, and restitution elasticity.
- **Physics Mechanics**:
  - **Spheres & Rigid Boxes**: 3D specular domes and glowing quantum core boxes with angular momentum.
  - **Gravitational Vortex**: Central singularity pull and tangential torque.
  - **Zero-G Flight & Radial Shockwave**: Weightless momentum physics and impulse blasts.
  - **Interactive Slingshot**: Drag-and-fling momentum launcher with trajectory prediction arcs.
  - **Luminous Radiant Auras**: 7 distinct neon cyber palettes with multi-stop radial gradient glows.

## ⚡ Performance Optimizations

- **0% Background CPU**: `IntersectionObserver` auto-sleeps WebGL and Canvas 2D render loops whenever scrolled out of view.
- **Zero Software Blur Overhead**: Replaced CPU Gaussian `shadowBlur` with GPU-accelerated alpha compositing and radial gradient shaders.
- **144 FPS Smooth Scroll**: GPU-composited static background layer (`translateZ(0)`) eliminating document repaint bottlenecks.
- **Throttled Events**: Mousemove tracking and scroll spy handlers are synchronized with the display refresh rate via `requestAnimationFrame`.

## 🚀 Getting Started

### Local Setup:
Simply clone the repository and launch any local web server:

```bash
# Clone the repository
git clone https://github.com/sharadgholse4/portfolio.git
cd portfolio

# Run with Python
python -m http.server 3000

# Or run with Node.js npx
npx serve .
```

Open your browser at `http://localhost:3000/`.
