## 📖 About The Portfolio

This project is a personal developer portfolio built to showcase my technical skills, software projects, and engineering journey. It features a clean, responsive design with interactive visual labs demonstrating core computer science and web development concepts.

### ✨ Key Features

- **Responsive Design**: Clean layout that adapts smoothly across mobile, tablet, and desktop screens.
- **Interactive 3D Skill Cosmos**: An interactive 3D constellation visualizer built with Canvas 2D and Three.js, mapping out technical skills with brand icons.
- **Interactive Simulations Lab**: Live interactive demonstrations of algorithms (Quicksort, Dijkstra, B-Tree memory hierarchy) and real-time socket communications.
- **System Architecture Modals**: Interactive blueprint diagrams explaining software design and component flows.
- **Tactile Audio Feedback**: Subtle, procedural sound synthesis powered by the Web Audio API for interactive elements.
- **Smooth Navigation**: Optimized scrolling performance and animated page transitions.

---

## 🛠️ Built With

- **HTML5 & CSS3**: Semantic markup and modern CSS styling with flexbox, grid, and animations.
- **JavaScript (ES6+)**: Core application logic and interactive features.
- **Three.js & Canvas 2D**: 3D interactive graphics and custom visualizer simulations.
- **GSAP & Lenis**: Smooth scroll choreography and reveal animations.
- **Web Audio API**: Lightweight in-browser sound synthesis.

## 🚀 Running Locally

To run the portfolio website on your local machine:

```bash
# Clone the repository
git clone https://github.com/sharadgholse4/portfolio.git
cd portfolio

# Start a local web server (using Python)
python -m http.server 3000

# Or using Node.js
npx serve .
```

Then open `http://localhost:3000` in your web browser.
